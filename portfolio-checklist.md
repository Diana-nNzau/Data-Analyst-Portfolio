# Data Analyst Portfolio Checklist

- [ ] About/bio section (who I am, career focus)
- [ ] 2–4 featured projects, each with: problem statement, data source, tools used, process, key visualization(s), and takeaway/impact
- [ ] Clear, consistent visual presentation style across projects
- [ ] Code and/or notebooks linked (e.g., to GitHub) for technical credibility
- [ ] Resume/CV linked or embedded
- [ ] Contact info / LinkedIn / GitHub links
- [ ] At least one project reflecting a genuine personal interest (not just a tutorial dataset)
- [ ] Proofread, working links, mobile-friendly if it's a website

*Update this checklist as each item is completed while progressing through the course.*
